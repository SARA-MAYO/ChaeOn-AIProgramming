============================================================
[기능 3 - 상태 변화 분석] 실행 로그 (log.txt)
============================================================
- 실행 명령 : python state_change_analysis.py
- 입력      : sample_chat_log.json (기능 1·2 라벨이 붙은 데모 채팅 65건, 발신자 4명)
- Seed      : 42 (기능3 자체 학습 없음 — 시드는 라벨 검수 미리보기 랜덤 샘플에만 사용)
- 데이터셋  : 별도 학습/검증/테스트셋 미사용 (기능 1·2 출력 라벨 + 채팅 로그만 입력)
