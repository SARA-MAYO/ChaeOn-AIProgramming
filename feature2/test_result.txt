============================================================
[기능 2 - 공격성 탐지] 최종 모델 선정용 비교 실험 결과
============================================================
※ 이 파일은 "실제로 어떤 모델을 쓸지 정하기 위한" 비교(시뮬레이션)
   과정(test_aggression_detection.ipynb)의 요약 결과입니다.
   여기서 선정된 모델의 정식 학습/평가는 aggression_detection.ipynb 에서 진행합니다.

[데이터셋]
- 출처   : AIHub 텍스트 윤리 검증 데이터셋 (talksets-train-1_aihub.csv)
- 라벨링 : intensity 점수 기반 3단계 binning
           intensity < 1.0        -> 비공격(0)
           1.0 <= intensity < 1.8 -> 약한공격(1)
           그 외                  -> 강한공격(2)
- 정제   : 결측/공백/중복 문장 제거 후 69,309개

[공정 비교 설정]
- Seed  : 42 (transformers set_seed(42) + random_state=42)
- Split : Stratified 8:1:1 (두 후보 모델에 '동일' 적용)
          Train 55,447 / Validation 6,931 / Test 6,931
- 평가  : 동일한 Test set 으로 측정, 지표는 Accuracy / Macro-F1
          (Confusion Matrix 는 노트북 셀에서 시각화)

------------------------------------------------------------
[후보 모델 성능] (동일 Test set 6,931개 기준)
------------------------------------------------------------
- 후보1) TF-IDF + 로지스틱 회귀 : Accuracy 0.5403 / Macro-F1 0.49
- 후보2) KoELECTRA-small        : Accuracy 0.64   / Macro-F1 0.60

------------------------------------------------------------
[최종 선정]
------------------------------------------------------------
- 선정 모델 : KoELECTRA-small (monologg/koelectra-small-v3-discriminator)
- 선정 근거 : Accuracy / Macro-F1 모두에서 베이스라인보다 우수
              (클래스 불균형을 고려해 Macro-F1 을 1차 선정 기준으로 사용)

[적법성 확인]
- 학습  : 두 후보 모두 Train 만 사용
          (KoELECTRA 는 Validation 을 epoch 평가용으로만 사용)
- 테스트 : 학습 종료 후 동일 Test set 으로 1회만 측정 (테스트셋 누출 없음)

※ 위 수치는 직전 실행 기록(result.txt) 기준입니다. 노트북을 재실행한 경우
   마지막 "최종 모델 선정 결과" 셀에 출력되는 값으로 갱신하면 됩니다.
